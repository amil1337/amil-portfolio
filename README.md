# Amil's Portfolio

A personal portfolio website built with Astro, featuring a clean, responsive design, an automated Markdown-based blog, and a dynamic projects showcase.

## Features

* **Automated Blog System:** Write articles in standard Markdown (`.md`) format. The system automatically generates individual pages and updates the main blog list.
* **Dynamic Projects Showcase:** Easily add new projects using Markdown files with frontmatter, avoiding repetitive HTML coding.
* **Component-Based Architecture:** Uses reusable Astro layouts (`MainLayout`, `BlogLayout`) for consistent design across all pages.
* **Responsive Design:** Fully responsive layout that adapts seamlessly to desktop, tablet, and mobile screens.
* **Dark Mode Support:** Built-in toggle for switching between light and dark themes, with automatic preference saving.
* **SEO Friendly:** Clean HTML output generated by Astro's static site generation.

## Technologies

* Astro
* HTML5
* CSS3 (Custom Properties / Variables)
* Vanilla JavaScript
* Markdown
* Netlify (Hosting & Deployment)

## What I Learned

* **Astro Framework:** I learned how to migrate a static HTML/CSS website into a modern framework, utilizing component-based architecture for better maintainability.
* **Content Collections & Dynamic Routing:** I learned how to use `import.meta.glob` to automatically fetch and render data from Markdown files instead of hardcoding lists.
* **Markdown Integration:** I gained experience in separating content from design by writing articles in Markdown and using Astro layouts to render them dynamically.
* **Version Control & Deployment:** I improved my workflow by managing the project with Git and setting up continuous deployment via GitHub to Netlify.
* **CSS Scoping and Global Styles:** I learned how to manage global styles alongside component-specific styles within the Astro environment, specifically handling the styling of generated Markdown content (like `<pre>` and `<code>` blocks).

## Getting Started

1. Clone the repository
2. Install dependencies using `npm install`
3. Run the development server with `npm run dev`
4. Visit `http://localhost:4321` in your browser
5. To add a new blog post, create a `.md` file inside `src/pages/blog/`
6. To add a new project, create a `.md` file inside `src/projects/`
